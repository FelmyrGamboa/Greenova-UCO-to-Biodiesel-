The current dark theme is the default visual identity of Greenova.

Keep:
- Existing dark backgrounds
- Existing dark cards
- Existing typography hierarchy
- Existing restrained green accents
- Existing layout
- Existing component styling

The Dark Theme option should restore/use this existing default dark appearance.

--------------------------------------------------
6.2 LIGHT THEME
--------------------------------------------------

When the user selects:

"Light Theme"

the entire application should automatically switch to a proper light-mode theme.

This should affect the entire application consistently, including:

- Page backgrounds
- Cards
- Panels
- Navigation
- Forms
- Text
- Borders
- Inputs
- Buttons where appropriate
- Charts
- Tables
- Status indicators
- Dashboard components
- Monitor components
- Batch components
- Settings components

The Light Theme should use:
- Light background
- White/light cards
- Dark readable text
- Appropriate borders
- Appropriate muted secondary text

The Light Theme should remain visually consistent with Greenova's existing design language.

Do NOT make the Light Theme neon or overly colorful.

--------------------------------------------------
6.3 THEME SWITCHING BEHAVIOR
--------------------------------------------------

The theme selection must actually change the application's appearance.

When:

Dark Theme → selected

the application should immediately use the existing default dark theme.

When:

Light Theme → selected

the application should immediately switch to the light theme.

The selected theme should remain active when navigating between pages.

For example:

Settings → Light Theme
→ Dashboard should also be Light Theme
→ Batches should also be Light Theme
→ Monitor should also be Light Theme

Likewise:

Settings → Dark Theme
→ all pages return to the existing default dark theme.

Do not create separate unrelated themes for individual pages.
